## Decisions where the spec was silent

1. **App `struct` names.** Spec says "{Suffix} is `Mac`, `IPad`, `TV`" and shows `RebornZune{Suffix}App`. I used `RebornZuneMacApp`, `RebornZuneIPadApp`, `RebornZuneTVApp` (PascalCase joined). The matching filenames mirror the struct names.
2. **Code signing.** Spec offers two options. I went with the second: `CODE_SIGNING_ALLOWED = NO` as the project base setting, then **overrode it to `YES` for the macOS target only** (with `CODE_SIGN_IDENTITY = "-"` so it ad-hoc signs) because macOS apps need to be signed (even ad-hoc) to be runnable, and the spec's macOS xcodebuild command does not pass `CODE_SIGNING_ALLOWED=NO`. iPadOS and tvOS targets inherit the base `CODE_SIGNING_ALLOWED = NO`, which matches the build commands that pass that flag explicitly. All three xcodebuild invocations succeed without a real provisioning profile, as required.
3. **Info.plist files.** xcodegen generates `Info.plist` per target into the source dir at the path I declared (`Apps/{platform}/Info.plist`). I set `GENERATE_INFOPLIST_FILE = NO` and provided the minimal keys (`CFBundleDisplayName`, `CFBundleName`, plus iPad orientations) via `info.properties` in `project.yml`. These plists are regenerated each time `xcodegen generate` runs, so I treat them as build artifacts (similar to the .xcodeproj). They currently are *not* in `.gitignore` because excluding them by name would also prevent committing any future hand-authored plist; this can be revisited if/when the repo is committed. The mediator handles git, so I am leaving this decision flagged here rather than locking it in.
4. **`Package.resolved`.** Added to `.gitignore`. Not in the spec's listed entries but conventional for SwiftPM-via-xcodegen flows; harmless if removed later.
5. **`SUPPORTS_MACCATALYST = NO` for the iPadOS target.** Set explicitly to ensure the iPad-only family stays iPad-only and Catalyst isn't accidentally enabled. Not required by spec but defensible.
6. **macOS `LSApplicationCategoryType = public.app-category.music`.** Cosmetic; unused outside of distribution. Trivially removable.
