# M14 — Resonant UI · tvOS visual parity (design v2)

## Background

M11 shipped the tvOS shell on top of M9. The design v2 bundle changed
the tvOS top nav and absorbed it into the same warm/black ramp the
iPad already adopted (M13). The tvOS-specific deltas from
`Resonant - tvOS.html` + the `[data-platform="tv"]` CSS rules:

| Area | v1 (M11) | v2 |
| --- | --- | --- |
| Top-nav brand text | `RESONANT` mono tag | Removed |
| Top-nav clock | Live time HH:mm | Removed |
| Top-nav vocab | `listen` (first pivot) | `home` |
| Pivot font | 40pt | 56pt |
| Paper | warm `#0E0D0A` | warm `#0E0D0A` (already unified in M13) |
| Mini-player | hidden (M11) | hidden (unchanged) |

This milestone closes the tvOS visual gap. It's a thin slice — the
heavy lifting (`ResonantLayout`, hit-area, color ramp) already shipped
with M13.

## Scope

* tvOS target only. Both the home wall and the browse screens.
* `ResonantLayout` adoption verification (tvOS lands at `.expanded`
  `.landscape` at 1920×1080 → `displayFontScale = 1.0` →
  type already calibrated; verify nothing regresses).
* Out of scope: real Apple TV deploy (sim only is fine), focus engine
  changes beyond what the vocab/font swap touches.

## Deliverables

1. `Sources/RebornZuneCore/Views/Resonant/TvTopNav.swift` — delete the
   `RESONANT` brand `Text` and the clock `Text` + the `Timer.publish`
   that drives it. Top nav becomes just the pivot row.
2. `Sources/RebornZuneCore/Views/Resonant/PivotNav.swift` (or a tvOS
   override in `TvTopNav` if cleaner) — pivot font size lifts from
   42pt to 56pt **on tvOS only** (`#if os(tvOS)`), tracking scaled
   proportionally (`-0.01 × size`).
3. `Sources/RebornZuneCore/Views/Resonant/Screens/TvHomeScreen.swift`
   (or wherever pivot labels live for tv) — first pivot label changes
   from `"listen"` → `"home"`. Matches the shared `PivotID` enum
   (`.home.label = "home"`); confirm no separate tv mapping diverged.
4. Sanity-check `\.resonantLayout` reaches tvOS via the default env
   value. At 1920×1080 it'll bucket as `.expanded .landscape`, scale
   1.0 — nothing should visibly change but the new modifiers
   (`resonantTag`, `.resonantScaledFont`) shouldn't crash for missing
   environment either.

## Acceptance criteria

1. `xcodebuild -project RebornZune.xcodeproj -scheme RebornZune-tvOS -destination "platform=tvOS Simulator,name=Apple TV 4K (3rd generation)" build` exits 0.
2. App launches on tvOS sim; home wall renders.
3. Top nav has no `RESONANT` text and no clock. Pivot row is the only
   content above the wall.
4. First pivot reads `home` (not `listen`); selecting it routes to
   `Home` as today.
5. Pivot row glyph height visibly larger than in M11 — measured ~56pt
   vs 40pt.
6. Now Playing dismiss via remote Back still works (no regression
   from M11).
7. mac + iPad continue to build and behave unchanged.

## Out of scope

* Real Apple TV hardware deploy.
* Focus engine / Siri Remote keyboard refresh.
* tvOS panorama curation (`TvHomeScreen` first pick copy — M15).
