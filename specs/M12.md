# M12 — Resonant UI · macOS visual parity (design v2)

## Background

After M9 shipped the macOS Resonant redesign, the user iterated on the
design prototype (`reborn-zune` handoff bundle, hash `ryU1iPUquET35bUxQZJcHQ`)
and landed on a small set of tweaks that the native app does not yet
match. This milestone closes the gap to **100% visual parity with the
v2 macOS sketch** (`Resonant.html`).

The diff between v1 and v2 design bundles is intentionally narrow:

| Area | v1 default | v2 default |
| --- | --- | --- |
| `data-theme` | `"light"` | `"dark"` |
| `data-chrome` | `"on"` (36px traffic-light gutter) | `"off"` (no gutter) |
| `.pivots` padding-top (chrome=off) | n/a | 56px |
| Home panorama padding-top | 18px | 48px |

(Theme already defaults to dark in the Swift app — M9 polish.)

## Scope

macOS only. iPad / tvOS deltas exist in v2 (status bar removed, OLED
black `--paper`, tvOS top-nav vocab) and will land in M13 / M14.

## Deliverables

1. **`Apps/macOS/RebornZuneMacApp.swift`** — adopt
   `.windowStyle(.hiddenTitleBar)` so the macOS window no longer renders
   a titlebar. Native traffic lights stay (functional necessity) but
   float over the canvas as in the design.
2. **`Sources/RebornZuneCore/Views/Resonant/PivotNav.swift`** — top
   padding `28pt → 56pt` on macOS to compensate for the missing
   titlebar gutter (`styles.css:945`).
3. **`Sources/RebornZuneCore/Views/Resonant/Screens/HomeScreen.swift`**
   — panorama page padding-top `18pt → 48pt` so the eyebrow tag and
   display title sit lower (`screens/home.jsx:252`).

## Acceptance criteria

1. `xcodebuild -project Apps/macOS/RebornZune.xcodeproj -scheme "Reborn Zune" build` exits 0.
2. Running app on macOS shows no titlebar / window title text. Traffic
   lights remain in the top-left corner.
3. Pivot row sits ~56pt below the top edge (vs 28pt before).
4. Home panorama eyebrow tag (`TODAY · …`) sits ~48pt below the pivot
   row (vs 18pt before).
5. No regressions on iPad or tvOS targets — build all three.

## Out of scope

* iPad pure-black paper / status-bar removal — M13.
* tvOS top-nav rewrite (drop brand + clock, font 40→56, vocab `home`) — M14.
* Anything beyond the four-row diff table above.
