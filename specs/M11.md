# M11 — Resonant UI (tvOS)

Apply the Resonant design system to tvOS. This is a **bigger rewrite** than iPad because tvOS swaps the input model (focus engine, no cursor, no touch), the scale (10-foot viewing → 1920×1080 with bigger type), and the chrome (no mini-player anywhere, no back button on Now Playing).

Per `Resonant - tvOS.html` + the `tv-*.jsx` screen files + `styles.css#data-platform="tv"`.

## Design summary

- Canvas: **1920×1080**.
- **No window chrome, no mini-player**. The app is always full-bleed.
- **Top nav** strip with brand (`● RESONANT` 13pt mono caps) + 5 pivots at 40pt + clock at right (12pt mono).
- **Focus engine**: arrow keys / Siri Remote pad navigates a focus grid; Enter activates; Esc/Back returns. Focused items lift + magenta outline + magenta caption.
- **Hard-rectangle buttons** (`.tv-btn`): no pills, no glows. Primary fill = magenta on focus. Border 1pt.
- **`--display-size: 280px`** — bigger type for distance viewing.
- **Page header**: eyebrow tag → 240pt headline → 48pt descender room before the filter chips beneath.
- **Now Playing**: full-bleed tile wall + sepia/magenta overlays, **no back button** (use Siri Remote Menu / Esc / Backspace), **no top nav** when in Now Playing.
- **Search**: single-row alphabet keyboard (`[␣] a b c … z [⌫]`), not a full QWERTY.
- **Home panorama**: same 5 picks but at TV scale; the indicator at bottom-left is **focusable**: when focused it shifts the active dot + counter prefix to magenta and reveals a `← → SCROLL PICKS` mono hint.

## Deliverables

### 1. Platform routing

`ResonantApp` already accepts `platform: .tv`. When `.tv`:
- Hide the mini-player (already hidden on `.nowPlaying`; on tv hide everywhere).
- Replace `PivotNav` with `TvTopNav`.
- Pass canvas width 1920 to HomeScreen for the panorama.
- Use density `.comfortable` (which yields `--display-size: 240`); override to `--display-size: 280` via a tv-specific constant.

### 2. Focus engine

SwiftUI provides `.focusable()` + `@FocusState` natively for tvOS. We don't need to roll our own grid like the prototype did — SwiftUI's spatial focus engine handles arrow-key navigation when each focusable element has a stable frame.

Per-element treatment when `focused`:
- Magenta outline (`.overlay(Rectangle().strokeBorder(.magenta, lineWidth: 3))` or for tv-card a magenta caption + lift).
- Scale 1.0 → 1.05 lift.
- Animated 240ms.

### 4. App entry rewrite

- `Apps/tvOS/ContentView.swift` — hosts a `TvResonantApp` that switches between the tvOS screen variants. tvOS bundles its music as resources (per the existing `Apps/tvOS/Resources/UserMusic` folder reference), so the empty-state folder picker isn't needed.
- Delete `PlayerChrome` usage from `Apps/tvOS/ContentView.swift`.

## Out of scope

- Apple TV remote click-pad simulation in development (we use arrow keys via SwiftUI's built-in focus engine, which is what tvOS apps do).
- Smart shuffle / queue-from-focus behaviours.
- Voice (Siri) search.
- Real-time clock in the top nav — it can show static `9:41` or the system clock if cheap.
- Panorama momentum tuning past a basic snap.
