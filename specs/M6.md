# M6 — Audio engine + Now Playing

Wrap `AVQueuePlayer` in a SwiftUI-friendly observable engine. Wire it to
`MPNowPlayingInfoCenter` and `MPRemoteCommandCenter` so lock-screen, AirPods
squeeze, Apple TV remote play/pause, and Control Center all work without per-app
plumbing. Configure the iOS/iPadOS/tvOS `AVAudioSession` so audio survives
backgrounding and locking the device.

No UI in this milestone beyond minimal proof-of-life in DefaultContent. Folder
picker and full app shell are M7.

## Deliverables

### 1. `PlaybackEngine` in `Sources/RebornZuneCore/Audio/`

#### `PlaybackEngine.swift`

```swift
import Foundation
import AVFoundation
import Observation

@MainActor
@Observable
public final class PlaybackEngine {
    public private(set) var state: PlaybackState
    public private(set) var currentItem: Music?
    public private(set) var queue: [Music]
    public private(set) var currentTime: TimeInterval
    public private(set) var duration: TimeInterval

    public var isShuffling: Bool         // setter triggers queue rebuild if engaged
    public var repeatMode: RepeatMode

    public init()

    /// Replace the queue. `startingAt` is the index in the unshuffled queue
    /// to begin playback from; if `isShuffling` is true the position is
    /// preserved relative to the shuffled order.
    public func setQueue(_ items: [Music], startingAt index: Int = 0)

    public func play()
    public func pause()
    public func togglePlayPause()
    public func next()
    public func previous()

    /// Jump to a specific track in the queue if present. No-op if not in queue.
    public func skip(to item: Music)

    /// Seek to a position in the current item (clamped to 0...duration).
    public func seek(to seconds: TimeInterval)
}

public enum PlaybackState: Sendable, Equatable {
    case stopped
    case playing
    case paused
    case buffering
}

public enum RepeatMode: Sendable, Equatable {
    case off
    case all   // wraps to first track after last
    case one   // current track loops indefinitely
}
```

Implementation notes:
- Internally uses an `AVQueuePlayer` and a parallel `[AVPlayerItem]` array
  built from the `Music` queue's URLs.
- Observes `currentItem` of the AVQueuePlayer with KVO; updates
  `self.currentItem` and triggers Now Playing refresh.
- A `CADisplayLink`-equivalent timer or `AVPlayer.addPeriodicTimeObserver`
  drives `currentTime` updates at ~5 Hz (don't burn CPU at 60 Hz for a
  minute hand).
- On `next()` past the end with `repeatMode == .off`, transitions to `.stopped`.
- On `next()` past the end with `repeatMode == .all`, wraps to index 0.
- With `repeatMode == .one`, on item end, seek to 0 and play again
  (don't advance queue position).
- Shuffle uses a deterministic Fisher-Yates with `SystemRandomNumberGenerator`
  (no seed needed here — shuffle is a UX concern, not a determinism concern).
- Engine MUST gracefully handle `Music` items whose `url` is unreachable
  (file deleted between queue-set and play): skip the item, log via
  `os.Logger`, advance to next.

### 2. `NowPlayingCenter` in `Sources/RebornZuneCore/Audio/`

#### `NowPlayingCenter.swift`

A small object that the engine owns and updates on track changes. Lives
behind `#if !os(macOS)` partly — `MPNowPlayingInfoCenter` works on macOS too
but the iOS `MPRemoteCommandCenter` integration matters more for sims.

```swift
import MediaPlayer

@MainActor
final class NowPlayingCenter {
    init()

    /// Wire remote command handlers. Idempotent.
    func registerCommands(
        play: @escaping () -> Void,
        pause: @escaping () -> Void,
        toggle: @escaping () -> Void,
        next: @escaping () -> Void,
        previous: @escaping () -> Void
    )

    /// Update Now Playing info on track change. Pass nil to clear.
    func update(item: Music?, currentTime: TimeInterval, duration: TimeInterval, rate: Double)
}
```

Sets `MPNowPlayingInfoCenter.default().nowPlayingInfo` with at minimum:
- `MPMediaItemPropertyTitle`
- `MPMediaItemPropertyArtist`
- `MPMediaItemPropertyAlbumTitle`
- `MPMediaItemPropertyPlaybackDuration`
- `MPNowPlayingInfoPropertyElapsedPlaybackTime`
- `MPNowPlayingInfoPropertyPlaybackRate`
- `MPMediaItemPropertyArtwork` (if `Music.artworkData` is non-nil — wrap in
  `MPMediaItemArtwork(boundsSize:requestHandler:)` lazy decoder).

Internal — not part of the public API. The engine triggers updates;
external callers don't need to touch it directly.

### 3. `AVAudioSession` configuration

#### `Sources/RebornZuneCore/Audio/AudioSessionConfigurator.swift`

```swift
@MainActor
enum AudioSessionConfigurator {
    /// Configure session for background-capable music playback on
    /// iOS/iPadOS/tvOS. No-op on macOS.
    static func configureForPlayback() throws
}
```

Implementation:
```swift
#if os(iOS) || os(tvOS)
let session = AVAudioSession.sharedInstance()
try session.setCategory(.playback, mode: .default, options: [])
try session.setActive(true)
#endif
```

The engine calls this on first `play()` and silently swallows errors — we
don't want playback to fail if session config has a transient hiccup.

### 4. Background audio entitlements / Info.plist

App targets need `UIBackgroundModes` containing `audio` so audio continues
when the screen locks (iOS/iPadOS) or the user goes to the home screen (tvOS).

Update `project.yml` for the iPadOS and tvOS targets to include this
in their Info.plist:

```yaml
info:
  properties:
    UIBackgroundModes: [audio]
```

macOS doesn't need this. Verify after `xcodegen generate` that the generated
Info.plist for iPadOS and tvOS contains the key.

### 5. Smoke-test wiring in DefaultContent

Modify each app's `ContentView.swift` `DefaultContent` to:
- Construct a `PlaybackEngine` (`@State`).
- Build a queue from `BundleLibrarySource` (tvOS) or just placeholder `Music`
  for now (macOS / iPadOS — file picker comes in M7).
- Show below the tile wall: a small status panel displaying current track
  title, current time, duration, and play/pause/next buttons.
- Auto-play on launch on tvOS only (showcase mode); macOS/iPadOS start paused.

This is the proof-of-life that the engine works. Polish/styling is M7.

If the engine has no items (e.g. macOS/iPadOS at this stage), the status
panel says "No music loaded — folder picker coming in M7."

### 6. Tests

#### `PlaybackEngineTests.swift`

These tests exercise state transitions and queue management WITHOUT actually
playing audio. Use Music items with placeholder URLs (you don't need them to
resolve to real files for state-machine tests).

- `testInitialStateIsStoppedNoItem`: fresh engine → state=.stopped, currentItem=nil, queue=[]
- `testSetQueueAdvancesToFirstTrack`: setQueue([a,b,c]) → currentItem=a
- `testSetQueueWithStartingAt`: setQueue([a,b,c], startingAt: 1) → currentItem=b
- `testNextAdvancesQueue`: with queue [a,b,c] at a, next() → b
- `testPreviousReverses`: at b, previous() → a
- `testNextAtEndStopsWithRepeatOff`: at c (last) with repeat=.off, next() → state=.stopped, currentItem=nil
- `testNextAtEndWrapsWithRepeatAll`: at c with repeat=.all, next() → a
- `testRepeatOneStaysOnTrack`: at b with repeat=.one, next() → still b
- `testSkipToInQueue`: skip(to: c) → currentItem=c
- `testSkipToOutOfQueueIsNoOp`: skip(to: unknown) → currentItem unchanged
- `testShuffleProducesQueuePermutation`: setQueue [a,b,c], isShuffling=true → queue contains the same set

Note that some assertions need to inspect what AVQueuePlayer would have done,
which can't be done without real items. For tests that need real audio
playback (e.g. timer firing, end-of-track detection), generate a 1-second
silent AAC/M4A in test setup using `AVAssetWriter` or check in a 1-second
test fixture. If you check in a fixture, place it under
`Tests/RebornZuneCoreTests/Resources/silent_1s.m4a`.

#### `NowPlayingCenterTests.swift`
- `testUpdateProducesExpectedKeys`: after `update(item:currentTime:duration:rate:)`,
  `MPNowPlayingInfoCenter.default().nowPlayingInfo` contains the expected keys.
- `testUpdateWithNilClearsInfo`: update(item: nil, ...) → nowPlayingInfo is nil or empty.

#### `AudioSessionConfiguratorTests.swift`
- `testConfigureDoesNotThrow`: on iOS/tvOS, configureForPlayback() succeeds in
  the test process. Wrap in `#if os(iOS) || os(tvOS)`.

## Notes for the executor

- The `@Observable` macro requires Swift 5.9+; Swift 6 supports it.
- `@MainActor` on `PlaybackEngine` is fine — all UI access happens on main, and
  AVPlayer must be configured on main.
- For tvOS bundled-music smoke test: drop a single small CC0 audio file in
  `Apps/tvOS/Resources/` (create the dir; it's not yet listed in project.yml's
  resources). Add to `project.yml` so it's included in the .app bundle.
  Keep it small — a few seconds is enough. https://freesound.org has CC0
  options; any short royalty-free clip is fine. Document the source/license.
- When the AVQueuePlayer's `currentItem` becomes nil (queue ended), don't
  retain a reference to the dead player — trigger your own state.stopped
  transition.
- For the `MPMediaItemArtwork` decoder, return a `UIImage` (iOS) or
  `NSImage` (macOS). Use the appropriate `#if`.
- Use `AVPlayerItem.statusObserver` or KVO with `addObserver`. Modern Swift
  prefers `AVPlayerItem.publisher(for: \.status)` from Combine — that's fine
  too if your team is OK with Combine. (No external deps; Combine is a system
  framework.)
- Tests for AVPlayer behavior are notoriously flaky — keep them logical
  state-machine tests where possible. End-of-track and timer tests can be
  smoke-only via the visual integration in DefaultContent.
