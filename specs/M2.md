# M2 — Library sources + domain types

Build the layer that turns "audio files on disk" into the in-memory `Music` /
`Album` / `Artist` graph that the tile wall consumes. No UI in this milestone.

## Deliverables

### 1. Domain types in `Sources/RebornZuneCore/Models/`

#### `Music.swift`

```swift
public struct Music: Identifiable, Hashable, Sendable {
    public let id: String              // stable; derived from URL.path
    public let url: URL                // location on disk (or in-bundle)
    public let title: String           // never empty; falls back to filename
    public let artist: String?
    public let albumArtist: String?
    public let albumTitle: String?
    public let year: Int?
    public let duration: TimeInterval  // seconds; 0 if unknown
    public let artworkData: Data?      // raw image bytes from the file's metadata; nil if absent

    public init(
        id: String, url: URL, title: String, artist: String?,
        albumArtist: String?, albumTitle: String?, year: Int?,
        duration: TimeInterval, artworkData: Data?
    )
}
```

`id` MUST be derived deterministically from `url.path` (use the path itself
or its SHA-256). Two `Music` instances representing the same file MUST have
equal `id`s.

#### `Album.swift`

```swift
public struct Album: Identifiable, Hashable, Sendable {
    public let id: String              // hash of (albumTitle, privilegedArtist)
    public let title: String           // "Unknown Album" if source had no album tag
    public let albumArtist: String     // see "privilegedArtist" rule below
    public let year: Int?              // earliest non-nil year among tracks
    public let tracks: [Music]         // ordered (see ordering rule below)
    public var artworkData: Data? {    // first track's artwork
        tracks.first?.artworkData
    }
}
```

**privilegedArtist rule** (carried over from the UWP `LibraryViewModel`):
1. If `albumArtist` is non-nil and not "Unknown Artist", use it.
2. Else if `artist` is non-nil and not "Unknown Artist", use it.
3. Else use `"Unknown Artist"`.

**Track ordering inside an album**: sort by `title` ascending. (Track-number
metadata is out of scope for M2.)

#### `Artist.swift`

```swift
public struct Artist: Identifiable, Hashable, Sendable {
    public let id: String              // hash of name
    public let name: String
    public let albums: [Album]
}
```

#### `LibraryGrouping.swift`

A pure free function (or static method) that turns `[Music]` into the
album/artist tree:

```swift
public enum LibraryGrouping {
    public static func albums(from tracks: [Music]) -> [Album]
    public static func artists(from albums: [Album]) -> [Artist]
}
```

### 2. `LibrarySource` protocol in `Sources/RebornZuneCore/Library/`

```swift
public protocol LibrarySource: Sendable {
    /// Load all audio tracks visible to this source.
    /// May throw on permission failures, missing folder, etc.
    /// Returns an empty array (NOT an error) when the source contains no audio.
    func load() async throws -> [Music]
}
```

### 3. `MetadataExtractor` helper in `Sources/RebornZuneCore/Library/`

Internal (not `public`) helper:

```swift
struct MetadataExtractor {
    /// Reads tags from the file at `url` using AVFoundation and produces a Music.
    /// Falls back gracefully on missing tags (uses filename for title, etc.).
    /// Throws only on unrecoverable IO errors.
    static func extract(from url: URL) async throws -> Music
}
```

Use the modern `AVAsset.load(.metadata)` async API. Do NOT use the deprecated
synchronous `AVAsset.metadata` accessor.

Mapping rules (concrete):

| Music field | AVMetadataItem source (in order; first non-nil wins) |
| --- | --- |
| title | `commonKey == .commonKeyTitle` → fall back to `url.deletingPathExtension().lastPathComponent` |
| artist | `commonKey == .commonKeyArtist` |
| albumArtist | iTunes `albumArtist` key, then `commonKeyAlbumName`-adjacent key — leave `nil` if absent |
| albumTitle | `commonKey == .commonKeyAlbumName` |
| year | `commonKey == .commonKeyCreationDate` parsed as Int year, else iTunes `year` key |
| duration | `try await asset.load(.duration).seconds` |
| artworkData | `commonKey == .commonKeyArtwork` `.dataValue` |

### 4. `FolderLibrarySource` in `Sources/RebornZuneCore/Library/`

```swift
public final class FolderLibrarySource: LibrarySource {
    public init(folder: URL)
    public func load() async throws -> [Music]
}
```

- Recursively enumerate the folder for files with extensions `.mp3`, `.m4a`, `.mp4`, `.aac`.
- For each file, call `MetadataExtractor.extract(from:)` concurrently
  (use `withTaskGroup` or `async let` — bounded concurrency, max 8 in-flight).
- Skip files whose extraction throws; do not let one bad file fail the whole load.
- Result ordered by track title ascending.

### 5. `BundleLibrarySource` in `Sources/RebornZuneCore/Library/`

```swift
public final class BundleLibrarySource: LibrarySource {
    public init(bundle: Bundle = .main, subdirectory: String? = nil)
    public func load() async throws -> [Music]
}
```

- Enumerate `bundle.urls(forResourcesWithExtension:subdirectory:)` for each
  supported audio extension.
- Same metadata pipeline as `FolderLibrarySource`.
- If `subdirectory` is provided, restrict to that subdirectory inside the bundle.

### 7. Tests in `Tests/RebornZuneCoreTests/`

Add at least:

#### `MusicTests.swift`
- `testIDIsDerivedFromURL`: two `Music` instances with the same URL get equal IDs; different URLs get different IDs.
- `testHashableEquality`: Hashable conforms to Equatable's contract.

#### `LibraryGroupingTests.swift`
- `testAlbumGroupingByAlbumAndArtist`: tracks with same `(albumTitle, albumArtist)` group together; differing albumArtist splits them.
- `testPrivilegedArtistRule`: track with only `artist` (no `albumArtist`) groups under that artist; track with both prefers `albumArtist`; `"Unknown Artist"` is treated as nil for grouping.
- `testEarliestYearWins`: album.year is the earliest non-nil year from its tracks.
- `testTrackOrdering`: album tracks are sorted by title ascending.
- `testEmptyInput`: `albums(from: [])` returns `[]`.

#### `BundleLibrarySourceTests.swift`
- `testEmptyBundleReturnsEmpty`: pointing at a bundle with no audio files returns `[]` (use `Bundle(for: type(of: self))` of the test class — the test bundle has no audio).

#### `FolderLibrarySourceTests.swift`
- `testEmptyFolderReturnsEmpty`: temp directory created via `FileManager.default.url(for: .itemReplacementDirectory, ...)` returns `[]`.
- `testNonExistentFolderThrows`: a URL pointing at a non-existent directory throws.

You do NOT need to test `MetadataExtractor` against real audio files in M2 —
that's M7's integration test. Pure-logic tests of grouping/IDs are what we want here.

## Out of scope for M2

- `NSMetadataQuery` / live updates — the protocol is single-shot `load()` for now
- Security-scoped bookmark management — `FolderLibrarySource` takes a plain `URL` and assumes the caller has access
- ThumbnailCache (deferred to M3 since it's a UI concern)
- Real audio test fixtures
- SwiftData persistence
- Any UI

## Notes for the executor

- The Apple async metadata API: `let metadata = try await asset.load(.metadata)`
  returns `[AVMetadataItem]`. Filter via `commonKey` or `key` casting.
- `AVAsset(url:)` is fine; the deprecated thing is `asset.metadata` (sync). Use `asset.load(.duration)`, `asset.load(.metadata)` instead.
- For SHA-256 use `CryptoKit` (`import CryptoKit; SHA256.hash(data:)`) — it's in
  the SDK on all our targets, no dependency needed.
- The privilegedArtist rule will read like nested ternaries. It's fine. Don't
  over-engineer.
- If a Spotlight-based variant is tempting, resist — it's M-later. M2 is filesystem scan.
