# M10 — Resonant UI (iPad)

Apply the Resonant design system built in M9 to the iPadOS app. iPad is a **delta on top of macOS**, not a fork — every screen file is reused.

Per `Resonant - iPad.html` + `ipad-shell.jsx` + the platform overrides in `styles.css#data-platform="ipad"`:

- Canvas is **1366×1024** (vs. macOS 1440×900). On real iPad the SwiftUI view fills the device; the spec value is just the design canvas.
- The macOS traffic-light chrome is replaced with an **iPadOS status bar** (time, signal/wifi/battery glyphs) and a **home indicator** at the bottom.
- **Touch-sized controls**: mini-player gets a 52×52pt art, 48pt play disc, 32pt secondary icons, 18pt track-row vertical padding.
- **Scrollbars hidden** (touch scroll doesn't need them).
- **Default density is `.cozy`** (`padX=56, padY=48, gap=24`).
- **Home panorama hides arrow buttons**; swipe-only.
- Panorama peek width is identical (173pt), so the visible slice of the next pick matches macOS.

Everything else — screens, navigation, mini-player rotator, Now Playing — uses the same SwiftUI views from M9 with platform-conditional modifiers.

## Deliverables

1. `IPadShell.swift` — analog of the macOS `chrome` band: status bar at top + home indicator bar at the bottom. Drops in between the window edge and `ResonantApp`'s VStack.
2. `ResonantApp` gains a `platform: ResonantPlatform` parameter (`.mac` / `.ipad`) that:
   - Switches density default (`.cozy` for iPad).
   - Passes `showArrows: false` to `HomeScreen`.
   - Applies touch sizing to the mini-player (a new `MiniPlayer.iPadSizing` flag).
3. `Apps/iPadOS/ContentView.swift` rewritten to host `ResonantApp(platform: .ipad)` wrapped in `IPadShell`.
4. `MiniPlayer` gains an `isTouch` flag that swaps in the iPad metrics from the spec.
5. `HomeScreen` already accepts `showArrows: Bool` from M9.

## Out of scope

- iPad-specific gestural niceties (edge swipe back, long-press menus) — later milestone.
- Split View / Slide Over layouts (single-orientation full-screen for M10).
- Apple Pencil interactions.
- Real status-bar values (always shows 9:41 + full bars).
