# M1 — Project scaffolding

Get the entire build machinery in place so future milestones can focus on logic
and visuals rather than tooling.

## Deliverables

### 1. Swift Package `RebornZuneCore`

Path: `Package.swift` at repo root.

Manifest requirements:
- `swift-tools-version: 6.0` (or higher)
- Single library product `RebornZuneCore`
- Single library target `RebornZuneCore` at `Sources/RebornZuneCore`
- Single test target `RebornZuneCoreTests` at `Tests/RebornZuneCoreTests`
- Platforms declared: `.macOS(.v14), .iOS(.v17), .tvOS(.v17)`
- No external dependencies in M1

`Sources/RebornZuneCore/RebornZuneCore.swift` must contain:
```swift
public enum RebornZuneCore {
    public static let version = "0.1.0"
}
```

`Tests/RebornZuneCoreTests/RebornZuneCoreTests.swift` must contain a single
XCTest case asserting the version string is non-empty.

### 2. xcodegen project spec

Path: `project.yml` at repo root.

Must define exactly three application targets:

| Target | Platform | Bundle ID | Source dir |
| --- | --- | --- | --- |
| `RebornZune-macOS` | macOS 14+ | `dev.yjd.rebornzune.macos` | `Apps/macOS` |
| `RebornZune-iPadOS` | iOS 17+ (iPad-only family) | `dev.yjd.rebornzune.ipados` | `Apps/iPadOS` |
| `RebornZune-tvOS` | tvOS 17+ | `dev.yjd.rebornzune.tvos` | `Apps/tvOS` |

Each target:
- SwiftUI app lifecycle (no AppDelegate)
- Includes the local Swift Package as a dependency on the `RebornZuneCore` product
- Display name `Reborn Zune`
- App icon: blank/default for now (M1 does not require icon assets)
- iPadOS target: device family iPad only (`TARGETED_DEVICE_FAMILY = 2`)
- tvOS target: standard tvOS top-shelf-less app

Code signing: configure for "Sign to Run Locally" / `CODE_SIGN_STYLE = Manual` with
empty signing identity, OR set `CODE_SIGNING_ALLOWED = NO` for simulator/macOS-debug
builds. The build commands in PROJECT_SPEC.md must succeed without a real
provisioning profile.

### 3. App target source files

Each app target gets exactly two Swift files:

`Apps/{platform}/RebornZune{Suffix}App.swift`:
```swift
import SwiftUI
import RebornZuneCore

@main
struct RebornZune{Suffix}App: App {
    var body: some Scene {
        WindowGroup {  // or appropriate scene per platform
            ContentView()
        }
    }
}
```

`Apps/{platform}/ContentView.swift`:
```swift
import SwiftUI
import RebornZuneCore

struct ContentView: View {
    var body: some View {
        VStack(spacing: 8) {
            Text("Reborn Zune")
                .font(.largeTitle)
            Text("{platform} — core v\(RebornZuneCore.version)")
                .font(.caption)
                .foregroundStyle(.secondary)
        }
        .padding()
    }
}
```

Where `{platform}` is one of `macOS`, `iPadOS`, `tvOS` and `{Suffix}` is `Mac`, `IPad`, `TV`.

For tvOS the scene type may be `WindowGroup` (default works). Apple TV does
not need any special focus handling at M1.

### 5. README

Path: `README.md` at repo root.

Brief — under 60 lines. Must contain:
- One-paragraph project description
- Prerequisites (`brew install xcodegen`, Xcode 16+)
- Setup commands: `xcodegen generate`
- Build/test commands (copy from PROJECT_SPEC.md)
- Pointer to `specs/` for the design docs

## Acceptance criteria

The evaluator must verify each of these by running the listed command and
inspecting output:

| # | Criterion | Verification |
| --- | --- | --- |
| A1 | Repo has the layout described in `PROJECT_SPEC.md → Project layout` | `ls -la` on repo root and key subdirs |
| A2 | `swift build` succeeds | Run from repo root, expect exit 0 and "Build complete!" |
| A3 | `swift test` succeeds and runs ≥1 test | Run from repo root, expect exit 0, parse output for "Test Suite ... passed" |
| A4 | `xcodegen generate` succeeds and produces `RebornZune.xcodeproj` | Run from repo root, expect exit 0, `ls RebornZune.xcodeproj` |
| A5 | `xcodebuild -project RebornZune.xcodeproj -scheme RebornZune-macOS -destination 'platform=macOS' -configuration Debug build` succeeds | Run after A4. Expect "** BUILD SUCCEEDED **" |
| A6 | `xcodebuild -project RebornZune.xcodeproj -scheme RebornZune-iPadOS -destination 'generic/platform=iOS Simulator' -configuration Debug build CODE_SIGNING_ALLOWED=NO` succeeds | Same — "** BUILD SUCCEEDED **" |
| A7 | `xcodebuild -project RebornZune.xcodeproj -scheme RebornZune-tvOS -destination 'generic/platform=tvOS Simulator' -configuration Debug build CODE_SIGNING_ALLOWED=NO` succeeds | Same |
| A8 | All three apps depend on `RebornZuneCore` and reference `RebornZuneCore.version` in `ContentView` | Read each `ContentView.swift`; confirm `import RebornZuneCore` and the version interpolation |
| A9 | iPadOS target's `TARGETED_DEVICE_FAMILY` is `2` (iPad only) | Inspect `project.yml` or the generated `pbxproj` |
| A10 | All three app bundle IDs match the table above | Inspect `project.yml` |

If any criterion fails, the milestone is rejected.

## Out of scope for M1

- App icons / asset catalogs (default placeholder is fine)
- Launch screens
- Anything in `Sources/RebornZuneCore/` beyond the `version` constant and a folder
  structure scaffold (empty subfolders are fine; they'll be filled by M2+)
- Tests beyond the single version-string test
- Running the apps in a simulator (only the build needs to succeed)
- CI configuration

## Notes for the executor

- xcodegen is already installed (`/opt/homebrew/bin/xcodegen`).
- The Xcode toolchain is Xcode 26.4.1; SDK macOS 26.4; iOS 26.4 + tvOS 26.4 simulators
  are available. Deployment targets (14/17/17) are below this, which is correct.
- Use `swift package init --type library` carefully — it creates a default layout
  that you'll need to adjust. Or hand-write `Package.swift` directly.
- For the SwiftPM dependency in `project.yml`, use xcodegen's
  `packages` and `dependencies: - package: RebornZuneCore` syntax. See
  https://github.com/yonaskolb/XcodeGen/blob/master/Docs/ProjectSpec.md for exact form.
- Do not commit `RebornZune.xcodeproj` or `.build/` (the `.gitignore` covers this).
